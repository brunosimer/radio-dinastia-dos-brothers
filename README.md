# Rádio Dinastia dos Brothers

Site e dois episódios da liga.

Hospedagem: Firebase Hosting, projeto `radio-dinastia-dos-brothers`.

Para publicar, execute `firebase deploy --only hosting` nesta pasta após autenticar a CLI na sua conta Google.

Os áudios podem ser substituídos e novos episódios adicionados editando `index.html`. Nenhum segredo ou credencial faz parte destes arquivos.
